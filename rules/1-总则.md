# 1 总则

版本 8.0.0。本目录九个文件是 Aham UI 的全部规则。取值以 [tokens.json](../tokens.json) 为准，样式以生成的 [aham.css](../aham.css) 为准，行为以 [aham.js](../aham.js) 为准。规则和这三个文件不一致时，按缺陷处理，改到一致。

## 1.1 适用范围

Aham UI 只覆盖一种界面：在电脑浏览器里使用的业务管理系统，例如 CRM、ERP、MES 的列表、单据、详情和设置页。

| 范围 | 状态 |
|---|---|
| 电脑浏览器，1280–1920px 宽 | 主要设计宽度，所有示例按这个范围验收 |
| 平板和手机浏览器 | 能用：导航收起、表单单列、触屏行高 44px；不单独设计 |
| 官网、营销页、阅读页 | 不覆盖 |
| macOS 应用、Office 文档、HTML 邮件 | 7.x 有过规则，8.0 删除；需要时另立项 |

## 1.2 设计原则

1. **密度服务于录入和核对。** 电脑上默认行高 36px，控件 32px；一屏能看到的行数比装饰更重要。44px 只用在触屏。
2. **层次靠留白、字号和字重。** 内容区是一张连续的白纸。分区用标题和间距区分，不套卡片、不加色块、不加竖条。
3. **颜色表达含义。** 主色蓝用于操作和焦点；状态色只表达状态；分类色只区分类别。颜色从不单独承载信息，旁边一定有文字或图标。
4. **线条细、对比低。** 分隔线 1px，用暖灰；静止的元素没有阴影，只有浮层有阴影。
5. **业务规则学 SAP Fiori。** 单据的显示和编辑、草稿、校验、消息、按钮位置、控件选型都按 Fiori 的做法定。这些做法经过大量企业的长期使用。
6. **键盘能做完全部操作。** 鼠标是可选的。快捷键登记在一张表里，界面上的提示和实际按键一致。
7. **状态写在页面上。** 未保存、审批中、已生效、已作废这些状态显示在单据头，打印件上也印出来。

## 1.3 视觉来源

| 来源 | 借鉴内容 | 依据的可靠程度 |
|---|---|---|
| Claude 客户端 | 中性色和表面层级、细线、圆角、浮层阴影、小而细的图标、少容器 | Anthropic 没有公开客户端的界面规范。中性色取自客户端截图量取，并和第三方仓库 Caho1/open-claude-ui 的取值核对过，两边不一致时以截图为准 |
| SAP Fiori | 内容密度、页型、对象页的显示态和编辑态、草稿、消息分级、语义色、选择控件选型、按钮位置 | 公开规范，来源链接见 [research/](../research/) 的规划草案 |
| Linear | 命令面板、快捷键、右键菜单、列表键盘、筛选 | 观察，7.2 起沿用 |

- 中性色、细线和浮层阴影按 Claude 客户端的量取值使用，取值和来源见 [2-视觉.md](2-视觉.md) 2.1。
- 主色、状态色、分类色、字体文件和图标由 Aham 自定，不取自任何一家。

## 1.4 术语

同一个概念全文只用一个词。

| 词 | 含义 | 不用的说法 |
|---|---|---|
| 单据 | 有编号、有状态、要提交或审批的业务对象，如报价单、订单、合同 | 表单、对象 |
| 记录 | 没有审批流程的业务对象，如客户、联系人 | 条目 |
| 显示态 / 编辑态 | 同一张单据只读和可改的两种状态，版式相同 | 查看模式、编辑模式 |
| 主按钮 | 一个页面上最主要的那个操作，蓝底白字，一页一个 | 强调按钮、CTA |
| 轻提示 | 屏幕右下角几秒后消失的确认消息（toast） | 提示条、吐司 |
| 提示条 | 单据头下方、说明整张单据状态或阻断原因的一条横幅（strip） | 横幅、通知栏 |
| 确认弹窗 | 不可撤销的操作之前问一次的模态窗口 | 对话框、确认框 |
| 字段状态 | 单个字段上的错误或提醒（value state） | 校验提示 |
| 消息列表 | 编辑态里收集全部字段错误和提醒的弹层 | 错误汇总 |
| 分类色 | 区分类别用的 6 个颜色 | 彩色、辅助色 |

## 1.5 文件分工

| 文件 | 内容 | 谁改 |
|---|---|---|
| tokens.json | 全部取值：颜色、字号、间距、尺寸、断点 | 改取值只改这里 |
| src/*.css | 样式源文件，按主题分文件 | 改样式改这里 |
| aham.css | 由 `node scripts/build.mjs` 生成，页面只引这一个 | 不手改 |
| aham.js | 行为脚本，ES 模块，无依赖 | 改行为改这里 |
| components/*.json | 每个控件和组合的结构、类名、状态、键盘 | 和 src、aham.js 一起改 |
| rules/*.md | 规则正文 | 规则变了先改这里 |
| examples/ | 示例页，用来核对规则 | 规则改了要同步 |

类名前缀 `wb-`，根节点 `.aham-workbench`，CSS 变量 `--wb-`。tokens.json 的键名就是变量名：键 `row` 生成 `--wb-row`。

## 1.6 规则的写法

- 每条规则写到能核对：写数值、写条件、写例外的判断标准。
- 规则之间冲突时，编号大的文件服从编号小的文件，同一文件里具体的服从笼统的。不写「本条优先于某条」的例外。
- 有参考实现的规则，写出函数名或类名；没有参考实现的，写明「8.0 没有参考实现」。
