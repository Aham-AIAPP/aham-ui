# 3 控件

每个控件的状态见 [examples/controls.html](../examples/controls.html)，结构和键盘见 [components/](../components/)。

## 3.1 控件清单

| 控件 | 类名或函数 | 高度 |

| 图标按钮 | `.wb-icon-btn` | 28px，点击区域 32px |
| 输入框、下拉、多行文本 | `.wb-field`，数字加 `.is-number`，小号加 `.sm` | 32px，`.sm` 28px |
| 单选组、复选框 | `.wb-choices` 包 `.wb-choice`，里面是 input | 点击区域 32px |
| 开关 | `.wb-switch` | 28 × 16px |
| 分段按钮 | `.wb-seg` | 28px |
| 页签 | `.wb-tabs` | 文字上下各 8px，当前项 2px 下划线 |

## 3.2 按钮

| 类型 | 写法 | 用在 |
|---|---|---|
| 主按钮 | `.wb-btn.primary` | 页面上最主要的操作：提交审批、保存、创建。一个页面只有一个，编辑态和显示态各算一个页面 |
| 普通按钮 | `.wb-btn` | 其他操作：编辑、打印预览、撤回 |
| 文字按钮 | `.wb-btn.ghost` | 次要且常用的操作：取消、工具栏里的开关 |
| 危险按钮 | `.wb-btn.danger` | 只出现在确认弹窗里：删除、作废。页面上的删除放进「更多」菜单，用红色文字 |
| 图标按钮 | `.wb-icon-btn` 或 `.wb-btn.icon-only` | 含义通用的操作：更多、关闭、搜索、刷新、导航开关、面板开关 |

- 一个按钮只用文字或只用图标，不同时用。这条按 SAP Fiori 的工具栏规则执行，下拉箭头不算图标。
- 只用图标的按钮必须有 `aria-label`，悬停时显示名称（`data-tooltip`）。业务操作（提交、审批、导出、分配）写文字，不做成图标按钮。
- 同一个按钮可以按状态换形式。例如列表的「筛选」：没有条件时是文字按钮，有条件后筛选行出现，按钮缩成图标。
- 按钮文字写动作本身，两到四个字：保存、提交审批、复制为新报价。确认弹窗的按钮也写动作（删除、作废、撤回），不写「确定」「是」。
- 确认弹窗和页脚工具栏里，取消在左、执行在右。

## 3.3 控件状态

控件有五种状态：可用、禁用、只读、隐藏、忙碌。按下表判断，规则来自 SAP Fiori 的「UI Element States」。

| 情况 | 状态 | 例子 |
|---|---|---|
| 当前用户在这个角色或这个单据状态下永远用不了 | 隐藏 | 没有审批权限的人看不到「批准」；已生效的报价单没有「编辑」 |
| 用户看得出为什么不能用，也知道怎么让它能用 | 禁用（`disabled`） | 明细表没选中行时，「删除行」禁用 |
| 用户看不出为什么不能用 | 保持可用，点击后说明原因 | 必填没填时点「提交审批」，弹出消息列表并定位到第一个问题 |
| 编辑态里不能改、但需要看的字段 | 只读：显示成文字，不做成禁用的输入框 | 单号、创建人、由明细算出的合计 |
| 暂时不能改、满足条件后可以改的字段 | 禁用的输入框，旁边写条件 | 「先选客户」之后才能选联系人 |
| 正在执行 | 忙碌：`aria-busy="true"` 并禁用，完成后恢复 | 保存中的「保存」 |

- 表格行前的勾选框永远可用。勾选的行里有不能处理的，执行时再说明，规则见 [6-反馈.md](6-反馈.md) 6.4。
- 批量操作条只在有勾选时出现，没有勾选时整条不显示，不做成一排禁用按钮。
- 禁用的控件不能取得焦点。需要让用户读到原因时，把原因写在控件旁边，不放在禁用控件的悬停提示里。

## 3.4 工具栏

工具栏指一组并排的操作按钮：单据头右侧、页脚、明细表标题行、列表批量条。

- 每个工具栏最多一个主按钮。整个页面也只有一个主按钮，所以多数工具栏没有主按钮。
- 从左到右：普通按钮（常用的靠近主按钮）→ 主按钮 → 「更多」。
- 宽度不够时，离主按钮最远的普通按钮先收进「更多」，主按钮最后收。
- 「更多」菜单里的顺序和按钮在工具栏上的顺序一致。删除、作废放在菜单最后，前面加一条分隔线，用红色文字。
- 一个工具栏最多 3 个可见的普通按钮，其余进「更多」。
- 明细表标题行的工具栏只放作用于这张表的操作：添加行、删除行、导入、导出、显示选项。
- 工具栏右对齐。只有页脚工具栏的消息按钮放在最左。

和 Fiori 的两处差异：Fiori 把强调按钮放在一组按钮的最左，把「取消」放在「保存」右侧；Aham 沿用网页常见的写法，主按钮在右，取消在左。

## 3.5 输入框

- 标签在上，值在下，标签和值之间 4px。标签用次要文字色，不加冒号。
- 必填在标签后加红色星号，只在编辑态显示。显示态里必填项没填时，值的位置写红字「没填」。
- 输入框宽度跟随表单列宽。数字、金额右对齐，等宽字体；单位写在框外右侧（`.wb-unit`），不放进框里。
- 占位文字写格式示例（「姓名 · 部门」「YYYY-MM-DD」），不写「请输入」，也不能代替标签。
- 系统生成的值（负责人、创建时间、单号）在编辑态也显示成文字，不做成禁用的输入框。
- 禁用的输入框只用在「暂时不能改、条件满足后可以改」的情况，旁边写明条件。
- 多行文本在单据里随内容长高，从一行开始；在弹窗里固定 3 行。

## 3.6 选择控件选型

下表按 SAP Fiori 的「Which Selection Control to Use」改写，选项数量指用户可以选的候选值个数。Fiori 的原表从 2 个选项起就用下拉；「2–5 个用单选组」是 Aham 加的，理由是选项少时全部摆出来，少点一次。

**单选：**

| 用户靠什么认出选项 | 2–5 个 | 6–12 个 | 13–200 个 | 200 个以上 |
|---|---|---|---|---|
| 一个值（如币种） | 单选组 | 下拉 | 选择菜单（带搜索） | 输入框带联想 + 值帮助弹窗 |
| 两个值（如编码 + 名称） | 单选组 | 下拉，选项写「编码 · 名称」 | 选择菜单（带搜索） | 输入框带联想 + 值帮助弹窗 |
| 三个及以上的值 | 选择弹窗（表格） | 选择弹窗（表格） | 选择弹窗（表格） | 值帮助弹窗 |
| 要按条件缩小范围 | 值帮助弹窗 | 值帮助弹窗 | 值帮助弹窗 | 值帮助弹窗 |

**多选：** 2–5 个用复选框组；6–200 个用选择菜单的多选模式（`createCommand` 的 `checked`）；200 个以上用值帮助弹窗。

**其他：**

| 场景 | 控件 |
|---|---|
| 是或否，保存时生效 | 一个复选框 |
| 是或否，改了立即生效（设置页） | 开关 |
| 切换同一份内容的看法（标准 / 紧凑，列表 / 看板） | 分段按钮 |
| 切换不同的内容（明细 / 条款 / 附件） | 页签 |
| 日期 | `<input type="date" class="wb-field">`，显示成 YYYY-MM-DD |
| 日期范围 | 两个日期框，写成「从 … 到 …」，后一个不早于前一个 |
| 数量、金额 | `.wb-field.is-number`，`inputmode="numeric"` 或 `"decimal"`，不用上下箭头的步进器 |
| 人员、客户等大量记录 | 选择菜单（带搜索），超过 200 个用值帮助弹窗 |

参考实现：选择菜单是 `openPicker()` 和 `createCommand()`。**选择弹窗（表格）、值帮助弹窗、输入框联想在 8.0 没有参考实现**，产品需要时按本表和 3.7 的条件自行实现，并补进本仓库。

## 3.7 值帮助弹窗

值帮助弹窗用于候选值多于 200 个，或者要先按条件缩小范围再选的字段，例如物料、供应商、会计科目。规则来自 SAP Fiori 的「Value Help Dialog」。

**入口**

- 输入框右侧放一个图标按钮打开弹窗，F4 也能打开。
- 输入框本身带联想：输入 2 个字以上，下方列出最多 10 条匹配项。
- 输入框可以直接写条件，离开输入框时转成条件标签：`=A100` 等于，`A100...A199` 介于，`<500` 小于，`>500` 大于，`!A100` 不等于，`*泵*` 包含。

**弹窗结构**（宽 880px，`--wb-dialog-wide`）

1. 标题：「选择 <字段名>」。
2. 两个页签：「搜索并选择」「定义条件」。字段只允许选已有的值时，只有第一个页签。
3. 「搜索并选择」：上方一个搜索框和一条筛选行（默认收起，「显示筛选」展开）；下方是结果表格，第一列是值，第二列是说明，最多 6 列。
4. 「定义条件」：每行一个条件，「包含 / 排除」+ 运算符 + 值，可以加多行。运算符有：等于、不等于、介于、包含、开头是、结尾是、小于、不大于、大于、不小于、为空。
5. 底部是已选区：每个已选值或条件是一个标签，可以单独移除；右侧「全部清除」。
6. 按钮：取消、确定。

**行为**

- 单选：点表格里的一行即选中并关闭弹窗，不需要「确定」。
- 多选：表格第一列是勾选框，勾选的值同步到已选区；点「确定」才写回字段。
- 打开时，字段里已有的值和条件预先放进已选区。
- 搜索结果超过 200 条时，表格只显示前 200 条，上方写「显示前 200 条，缩小搜索范围可以看到更多」。

## 3.8 状态

- 写法：6px 圆点加文字，`<span class="wb-status" data-tone="success"><b></b><span>已生效</span></span>`。
- `data-tone` 取 `draft`（空心圆）、`info`、`success`、`warning`、`danger`，不写为无色实心圆。各状态用哪个色见 [2-视觉.md](2-视觉.md) 2.2。
- 状态文字用正文色，只有圆点有颜色。
- 列表里的状态列、单据头、详情页都用同一种写法，不用彩色徽章或整行底色。

## 3.9 标签和分类

- 标签用来标类别，不能点击。能点击的筛选条件用 `.wb-chip`（见 [4-页面.md](4-页面.md) 4.4）。
- 一个值最多带两个标签。标签多于两个时，写前两个加「+ N」。
- 标签文字两到四个字。

## 3.10 提示条

提示条（`.wb-strip`）说明整张单据或整个页面的状态，放在单据头下面、正文上面。

| 色调 | 用在 |
|---|---|
| `info` | 审批中、正在处理、需要知道的说明 |
| `success` | 已生效、已完成 |
| `warning` | 已退回（写退回原因）、即将过期 |
| `danger` | 阻止提交的原因，例如必填没填 |
| 不写 | 已作废、已关闭这类没有好坏的状态 |

- 一页最多一条提示条。状态变了就换掉内容，不叠加。
- 提示条可以带一个按钮，例如「去填写」。
- 单个字段的问题标在字段上（字段状态），不放进提示条。
