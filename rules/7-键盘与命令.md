# 7 键盘与命令

本章落实设计理念的原则 10、11。页面上的每个操作都能只用键盘完成。同一个操作可以有四个入口：按钮、⌘K 命令面板、快捷键、右键菜单。四个入口调用同一份操作定义，结果一致。

## 7.1 快捷键表

所有快捷键登记在 `registerShortcut()`。按 ? 打开的帮助列表只显示已登记的按键。

| 按键 | 作用 | 范围 |
|---|---|---|
| ⌘/Ctrl + K | 命令面板 | 全局 |
| ⌘/Ctrl + B | 展开或收起侧栏 | 全局 |
| G 然后字母 | 转到侧栏里的一项，例如 G C 转到客户。字母写在侧栏项的 `data-go` 上 | 全局 |
| ? | 快捷键列表 | 全局 |
| Esc | 关闭最上面一层 | 全局 |
| C | 新建当前页的对象 | 列表 |
| / | 搜索 | 列表 |
| ↑ ↓ Home End | 移动当前行 | 列表 |
| 空格 | 预览当前行。列表不设预览时不拦截（4.7） | 列表 |
| Enter | 打开当前行 | 列表 |
| X | 勾选当前行 | 列表 |
| Shift + ↑ ↓ | 扩展勾选 | 列表 |
| S | 改状态类属性。状态由数据算出时不设 | 列表当前行、详情 |
| A | 改负责人 | 列表当前行、详情 |
| Shift + F10 或菜单键 | 当前行的操作菜单 | 列表当前行 |
| J / K | 下一条、上一条 | 详情 |
| E | 进入编辑态 | 单据显示态，单据状态允许修改时 |
| Enter 或 F2 | 编辑获得焦点的值 | 单据显示态 |
| ⌘/Ctrl + Enter | 保存、创建、发送评论 | 单据编辑态、新建弹窗、评论框 |
| → / ← | 展开或折叠、移到子行或父行 | 多层明细当前行 |
| + / − / 0 | 放大、缩小、适合页面 | 文件预览区 |
| PageUp / PageDown | 上一页、下一页 | 文件预览区 |

- 单个字母的快捷键只在焦点不在输入框、输入法没有组字时生效。带 ⌘/Ctrl 的在输入框里也生效。
- 两步的快捷键（G 然后字母）第二个键要在 1 秒内按下。侧栏收起时，悬停导航项显示名称和按键。字母取对象英文名的首字母：首页 H（home）、待办 I（inbox）、客户 C、商机 O、报价 Q、设置 S。首字母已被占用时，按侧栏从上到下的顺序，后出现的项取英文名里下一个没被占用的字母，例如合同 contract 的 C、O 已被占用，取 N；场景 scene 的 S、C 已被占用，取 E。侧栏底部的设置固定用 S。同一个产品里不能重复。参考实现在 `initShell()`。
- 单个字母的快捷键可以在设置里整体关闭（WCAG 2.1.4），用 `setSingleKeyShortcuts(false)`。关闭后，带 ⌘/Ctrl 的快捷键和列表当前行的方向键、空格、Enter、X 仍然可用。
- 表里的按键是保留键，产品不能改作他用。新增快捷键先登记，再出现在界面提示里。
- macOS 上显示 ⌘ ⇧ ⌥，其他系统显示 Ctrl Shift Alt（`formatKeys()`）。

## 7.2 命令面板

- ⌘/Ctrl + K 打开或关闭。宽 640px，距视口顶部 22vh。搜索框 48px 高，选项 40px 高，列表最高 384px。
- 有当前记录或单据时，顶部显示它的编号和名称，命令作用于它。
- 命令分组排列：当前记录 → AI → 操作 → 界面 → 跳转 → 帮助。有快捷键的命令在右侧显示按键。
- 名字以「…」结尾的命令进入下一级列表，在面板里原地替换；Esc 或空搜索框里按退格返回上一级。
- 执行后面板关闭，焦点回到打开前的位置，结果用轻提示确认。
- 参考实现：`initPalette()`。
- 「跳转」组用 `navCommands(root)` 从侧栏带 `data-go` 的导航项生成，名称和 G 加字母的按键和侧栏一致。当前页不列出。
- 「操作」组先列本页操作，用 `pageCommands(root)` 从页眉右侧的文字按钮生成：名称取 `data-tooltip` 或按钮文字，按键取 `data-keys`。禁用和隐藏的按钮不列出。只有图标的按钮（搜索、主题、面板开关）由「界面」组提供。

## 7.3 选择菜单

选择菜单是筛选、改属性、命令面板共用的列表。

- 顶部搜索框，选项不超过 4 个时可以不放。选项行 32px，左侧可以有 16px 图标，同一个列表里有一行带图标，其他行就留出同宽的空位。
- 高亮行用灰底，随方向键和鼠标移动。多选行左侧是勾选框，选中时墨色底白勾。选中的颜色不用蓝色。
- 焦点一直在搜索框里：↑↓ 循环移动，Enter 选择，Esc 关闭并把焦点还给触发按钮。
- 读屏：搜索框 `role="combobox"` 加 `aria-activedescendant`，列表 `role="listbox"`；用作操作菜单时是 `role="menu"`。
- 参考实现：`createCommand()`、`openPicker()`。

## 7.4 右键菜单

- 在列表行上右键，或当前行按 Shift + F10 打开。宽 256px。
- 分组顺序：改属性 → 打开类 → 复制类 → 删除。删除用红字，排在最后。
- 每个列表行的菜单至少有「打开」「复制编号」「复制链接」三项。当前用户能改负责人时加「指派…」或「更换负责人…」，能改状态时加「改状态…」。用户没有权限的项不出现，不显示成禁用。
- 有下一级的项右侧有箭头，选中后在同一个菜单里换成下一级，首项是「返回」。不弹出级联子菜单。
- 参考实现：`initContextMenu()`。

## 7.5 按钮提示

- 页眉和工具栏按钮悬停 500ms 或键盘聚焦时，在按钮下方显示名称和快捷键。
- 写法：`data-tooltip="名称"`，有快捷键时加 `data-keys="mod+b"`，按键必须在 7.1 的表里。
- 只有图标的按钮仍要写 `aria-label`，提示不能代替可访问名。
- 一次只显示一个；移开、失焦、Esc、滚动、点击时消失。触屏上不显示。
- 参考实现：`initTooltips()`。

## 7.6 焦点

- 焦点框 2px 主色，离元素 2px。系统开启增强对比度时 3px。
- 弹层、弹窗关闭后，焦点回到打开它的元素。
- 弹窗打开时焦点留在弹窗里，背后的内容不能操作。
- 列表里只有当前行在 Tab 顺序中；表格不声明为 ARIA grid，因为单元格不能逐格移动。
