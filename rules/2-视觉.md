# 2 视觉

所有数值来自 [tokens.json](../tokens.json)，表里的变量名可以直接在 CSS 里用。`node scripts/lint.mjs` 检查样式源文件有没有写死颜色、字号和圆角。

## 2.1 中性色

内容区纯白，面板、分隔线和文字用低饱和的暖灰（色相 40° 左右，饱和度 4%–15%）。暖灰看起来是「带一点暖的灰」，不发黄。

| 变量 | 亮色 | 暗色 | 用途 |
|---|---|---|---|
| `--wb-bg` | `#FFFFFF` | `#1C1B19` | 内容区、输入框、按钮底 |
| `--wb-panel` | `#F6F5F3` | `#252421` | 外框底、侧面板、表头、提示块 |
| `--wb-hover` | `#F6F5F3` | `#302E2B` | 悬停 |
| `--wb-selected` | `#EDEBE7` | `#363431` | 选中行、当前导航项 |
| `--wb-line` | `#E6E3DE` | `#3B3935` | 1px 分隔线、控件边框 |
| `--wb-ink` | `#262522` | `#F3F2EF` | 正文 |
| `--wb-muted` | `#6B6862` | `#A9A59D` | 标签、说明、次要文字 |
| `--wb-faint` | `#97938B` | `#7A766F` | 占位文字、空值「–」、禁用文字 |

`--wb-faint` 对白底只有 3.06:1，只能用在不承载信息的地方：输入框占位文字、空值、禁用控件。

## 2.2 主色、状态色和分类色

颜色分三组，每组有自己的使用范围。

| 组 | 变量 | 用在 | 不用在 |
|---|---|---|---|
| 主色 | `--wb-blue` `#336EE8`，主按钮底 `--wb-action` `#164EC3` | 主按钮、链接、焦点框、当前页签下划线、编辑框获得焦点时的边框 | 装饰、标题、分区标记 |
| 状态色 | `--wb-success` `--wb-warning` `--wb-danger` `--wb-info`，各配一个浅底 `-bg` | 状态圆点、状态图标、字段状态、提示条、消息列表 | 整行底色、按钮底色、装饰 |
| 分类色 | `--wb-cat-1` 到 `--wb-cat-6` | 16px 以内的图标、标签的色点和浅底、图表系列、头像底 | 文字颜色、大面积色块、表达好坏 |

状态色的含义固定，全系统不变：

| 色 | 含义 | 例子 |
|---|---|---|
| 成功 `success` | 已完成、已生效、通过 | 已生效、已审批 |
| 警示 `warning` | 可以继续，但要注意 | 已退回、即将到期、折扣超限 |
| 错误 `danger` | 必须处理才能继续，或已经失败 | 必填没填、已逾期、上传失败 |
| 信息 `info` | 中性的说明，正在进行 | 审批中、处理中 |
| 无色（`muted`） | 没有好坏 | 草稿（空心圆）、已作废、已关闭 |

分类色的规则：

- 同一个类别在全系统用同一个序号。例如「软件」是 `cat-1`，在报价明细、产品列表、图表里都是 `cat-1`。
- 一页里出现的分类色不超过 6 种。超过 6 类时，多出的类别用无色标签（`.wb-tag.is-plain`）。
- 标签写法：`<span class="wb-tag" data-cat="2">服务</span>`，浅底是分类色的 12%，文字仍是正文色。
- 图标写法：`<svg class="wb-cat-icon" data-cat="2">`。

## 2.3 对比度

下表由 `node scripts/lint.mjs --table` 按 WCAG 2 公式算出，lint 在低于要求时报错。

| 用途 | 前景 / 背景 | 亮色 | 暗色 | 要求 |
|---|---|---|---|---|
| 正文 | `ink` / `bg` | 15.33 | 15.37 | 4.5 |
| 面板上的正文 | `ink` / `panel` | 14.07 | 13.86 | 4.5 |
| 选中行的正文 | `ink` / `selected` | 12.87 | 11.08 | 4.5 |
| 次要文字 | `muted` / `bg` | 5.55 | 7.01 | 4.5 |
| 面板上的次要文字 | `muted` / `panel` | 5.10 | 6.32 | 4.5 |
| 占位文字和空值 | `faint` / `bg` | 3.06 | 3.81 | 2.5 |
| 主按钮文字 | `on` / `action` | 7.21 | 4.63 | 4.5 |
| 焦点框、链接图标 | `blue` / `bg` | 4.63 | 6.00 | 3 |
| 成功文字 | `success` / `bg` | 5.32 | 7.71 | 4.5 |
| 警示文字 | `warning` / `bg` | 5.19 | 8.09 | 4.5 |
| 错误文字 | `danger` / `bg` | 6.57 | 7.08 | 4.5 |
| 信息文字 | `info` / `bg` | 4.63 | 6.95 | 4.5 |
| 错误提示框里的文字 | `danger` / `danger-bg` | 5.69 | 6.33 | 4.5 |
| 待核对的值 | `ink` / `warning-mark` | 12.26 | 9.69 | 4.5 |
| 分类色 1–6 | `cat-n` / `bg` | 4.63–5.39 | 6.83–8.09 | 3 |

控件边框 `--wb-line` 对白底 1.28:1，低于 WCAG 对控件边界的 3:1。这是为了线条轻而做的取舍，靠下面两条补足：输入框有占位文字或标签指明位置；系统开启「增强对比度」时，边框换成 `#8C8880`（对白底 3.53:1）、次要文字加深、焦点框加粗到 3px。

## 2.4 字体

| 用途 | 字体 | 变量 |
|---|---|---|
| 界面文字 | Inter Variable，中文回退苹方、微软雅黑、思源黑体 | `--wb-font` |
| 数字、金额、编号、日期、代码 | JetBrains Mono，回退系统等宽字体 | `--wb-mono` |

- 管理界面只用无衬线字体，不用衬线体。
- Inter 随仓库自托管在 `assets/fonts/`，已内嵌进 aham.css 的 `@font-face`，不从第三方服务器下载。JetBrains Mono 没有随仓库提供，产品自行安装或托管，缺失时用系统等宽字体。
- 金额、数量、单价、编号、日期一律等宽，数字列右对齐，小数位数在同一列里一致。

## 2.5 字号和字重

| 变量 | 字号 | 用途 |
|---|---|---|
| `--wb-text-xs` | 12px | 表单提示、上标计数、打印件明细。全系统最小字号 |
| `--wb-body` / `--wb-text-sm` | 13px | 正文、表格、标签、按钮 |
| `--wb-text-base` | 14px | 分区标题、弹窗标题、浮层里的强调文字 |
| `--wb-title` | 20px | 页面标题（列表、设置）、打印件标题 |
| `--wb-detail-title` | 24px | 单据和详情的标题 |
| `--wb-total` | 24px | 金额汇总的大数字 |
| `--wb-touch-input` | 16px | 触屏上的输入框，防止 iOS 放大页面 |

字重三档：400 正文；500 表头、当前项、强调；600 页面标题和分区标题。不用 700。

## 2.6 间距

间距按 4px 递进：`--wb-s1` 4、`s2` 8、`s3` 12、`s4` 16、`s5` 24、`s6` 32、`s7` 48、`s8` 64、`s9` 96。

| 位置 | 取值 |
|---|---|
| 单据页左右边距 | `--wb-page-gutter` 32px，1600px 以上 48px |
| 单据分区之间 | 32px（`s6`） |
| 分区标题到内容 | 16px |
| 表单字段之间 | 上下 16px，左右 24px |
| 标签到值 | 4px |
| 按钮之间 | 8px |

## 2.7 尺寸

| 变量 | 取值 | 用途 |
|---|---|---|
| `--wb-row` | 36px | 列表行、表头、明细行的默认高度 |
| `--wb-row-compact` | 32px | 紧凑档，用户在显示选项里切换 |
| `--wb-row-double` | 48px | 两行内容的行（名称加编码） |
| `--wb-control` | 32px | 按钮、输入框、下拉 |
| `--wb-header-control` | 28px | 小号按钮和输入框：工具栏、页眉、弹层 |
| `--wb-field` | 28px | 表格单元格里的输入框 |
| `--wb-hit` | 32px | 小控件的最小点击区域 |
| `--wb-touch` | 44px | 触屏的行高和点击区域 |
| `--wb-header-row` | 40px | 页眉横条 |
| `--wb-icon` | 16px | 图标 |

同一页只用一档密度：表头、分组标题和数据行同高，随密度一起变。640px 以下或粗指针（触屏）时，行高换成 44px。

## 2.8 圆角、线条、阴影

| 项 | 规则 |
|---|---|
| 圆角 | 小元素 4px（`--wb-radius-sm`：标签、勾选框、键位提示）；控件和弹层 6px（`--wb-radius`：按钮、输入框、提示条、表格外框、菜单、弹层）；弹窗和外框 10px（`--wb-radius-lg`）；胶囊（`--wb-radius-pill`）只用于开关、进度条和头像 |
| 线条 | 一律 1px `--wb-line`。表格只画横线，不画竖线。分区之间不画线，用间距 |
| 阴影 | 静止的元素没有阴影。弹层、菜单用 `--wb-shadow-pop`，弹窗用 `--wb-shadow-float` |

## 2.9 图标

- 图标集用 Lucide（ISC 许可），雪碧图在 `assets/icons/aham-icons.svg`，写法 `<svg aria-hidden="true"><use href="assets/icons/aham-icons.svg#i-search"/></svg>`。
- 默认 16px，描边 1.5，颜色跟随文字（`currentColor`）。
- 图标颜色只有四种来源：文字色、主色（焦点或当前项）、状态色（状态图标）、分类色（类别图标）。
- 只有图标的按钮必须有 `aria-label`，悬停时显示名称（`data-tooltip`）。
- 不用 emoji、插画和彩色图形。

## 2.10 动效

| 变量 | 时长 | 用途 |
|---|---|---|
| `--wb-fast` | 120ms | 悬停、边框颜色 |
| `--wb-base` | 180ms | 弹层出现、面板展开 |
| `--wb-slow` | 280ms | 导航展开 |

缓动统一 `--wb-ease`。动效只用来表示「从哪里来、到哪里去」，不做装饰。系统开启「减少动态效果」时去掉过渡。

## 2.11 暗色

- 根节点 `data-theme="dark"` 切暗色，`data-theme="light"` 固定亮色，不写时跟随系统。
- 暗色的每个颜色单独取值，不是亮色反转；`color.dark` 和 `color.light` 的键必须一一对应，构建脚本会检查。
- 打印时一律用亮色，不论屏幕是哪个主题。
- 文件预览里的原稿不随主题反色。
