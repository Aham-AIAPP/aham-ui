# 2 视觉

本章落实设计理念的原则 1、6、7、8、9。所有数值来自 [tokens.json](../tokens.json)，表里的变量名可以直接在 CSS 里用。`node scripts/lint.mjs` 检查样式源文件有没有写死颜色、字号和圆角。

## 2.1 中性色和表面层级

中性色参考 Claude 客户端：内容区纯白，侧栏和外框比内容区深一档，灰色只给一行高的小元素。色值来自对 Claude 客户端截图的量取，并和第三方项目 open-claude-ui 公开的取值核对过，来源见 [docs/research/](../docs/research/) 的第二轮规划。

| 变量 | 亮色 | 暗色 | 用途 |
|---|---|---|---|
| `--wb-canvas` | `#EDECEB` | `#0B0B0B` | 外框、侧栏、打印预览的底 |
| `--wb-bg` | `#FFFFFF` | `#151515` | 内容区、侧面板、汇总栏、输入框 |
| `--wb-pop-bg` | `#FFFFFF` | `#1A1A19` | 弹层、菜单、弹窗 |
| `--wb-fill` | `#F3F3F3` | `#20201F` | 一行高的小元素：分段按钮、评论、提示条、禁用输入框 |
| `--wb-hover` | `#F3F3F3` | `#20201F` | 悬停，和 `--wb-fill` 同值 |
| `--wb-selected` | `#EBEBEA` | `#2C2C2A` | 选中行、按下、打开中的触发按钮 |
| `--wb-button` | `#F3F3F2` | `#252524` | 次要按钮的底：不画描边，靠底色识别 |
| `--wb-button-hover` | `#EBEBEA` | `#2E2E2C` | 次要按钮悬停 |
| `--wb-button-press` | `#E3E2E1` | `#383836` | 次要按钮按下、打开中 |
| `--wb-nav-hover` | `#E3E2E0` | `#191918` | 侧栏导航项的悬停 |
| `--wb-nav-selected` | `#D5D4D3` | `#232322` | 侧栏的当前项和按下 |
| `--wb-edge` | `#D6D5D3` | `#343432` | 工作面和外框的交界线 |
| `--wb-line` | `#E5E5E4` | `#2E2E2C` | 分栏线：页眉下线、侧面板左线、弹窗分栏 |
| `--wb-line-soft` | `#EFEFEE` | `#262624` | 行与行之间的线 |
| `--wb-line-strong` | `#8C8B89` | `#6E6E6B` | 输入框和开关的描边，对底色不低于 3:1 |
| `--wb-pop-edge` | `#E5E5E4` | `#3A3A38` | 浮层和弹窗外缘的 1px 线，写在浮层阴影里 |
| `--wb-ink` | `#151515` | `#F5F5F3` | 正文 |
| `--wb-ink-2` | `#525251` | `#C4C4C2` | 控件里的次要文字：视图页签的其他项、标签文字 |
| `--wb-muted` | `#666664` | `#A6A6A3` | 字段标签、表头、次要文字、图标、字段和设置项下方的辅助说明、占位文字、空值、时间戳 |
| `--wb-faint` | `#888886` | `#7B7B79` | 只用于图标和禁用文字 |

铺灰的面积：

1. 默认不为大区块铺灰。AI 草稿、代码、只读反馈可使用有明确语义的淡底。侧面板、汇总栏、属性栏用 `--wb-bg`，和内容区之间画一条分隔线。
2. 外框和侧栏用 `--wb-canvas`，比内容区深一档（亮色 LCH 亮度差约 7）。深一档让内容区成为视线中心（原则 1）。
3. `--wb-fill`、`--wb-hover`、`--wb-selected` 优先用在行级交互状态；大区块淡底需说明语义。
4. 表头不铺灰，用字重 500、次要文字色和下方分隔线区分。

需要读的文字一律不低于 4.5:1。辅助说明、占位文字和空值用 `--wb-muted`（对白底 5.75:1）。`--wb-faint` 只留给图标和禁用文字，WCAG 2 对禁用控件的文字不作对比度要求。系统开启「增强对比度」时，`--wb-muted` 和 `--wb-faint` 都换成 `#474746`（对白底 9.30:1）。

## 2.2 主色、状态色和分类色

颜色分三组，每组有自己的使用范围。

| 组 | 变量 | 用在 | 不用在 |
|---|---|---|---|
| 主色 | `--wb-blue` `#336EE8`；主按钮底 `--wb-action` 使用中性色，与 `--wb-on` 配对 | 焦点框、当前项标记（当前页签下划线、键盘焦点行的边线、带事件阶段条上的当前站）、编辑框获得焦点时的边框、进行中的阶段图标、记录详情页关键信息里的主数字（一页一个，通常是金额） | 正文链接、装饰、标题、分区标记、侧栏的当前项 |
| 状态色 | `--wb-success` `--wb-warning` `--wb-danger` `--wb-info`，各配一个浅底 `-bg` | 状态圆点、状态图标、字段状态、提示条、消息列表 | 整行底色、按钮底色、装饰 |
| 分类色 | `--wb-cat-1` 到 `--wb-cat-6` | 16px 以内的图标、标签的色点和浅底、图表系列、头像底、文件类型图标 | 文字颜色、大面积色块、表达好坏 |

正文链接的写法：

- 正文和说明里的链接用正文色，加 1px 下划线。下划线用 `--wb-line-strong`，离文字 3px；悬停时变成正文色。写法是 `.wb-link`。
- 列表里的名称、面包屑、侧栏和属性栏里的值是整块可点的，不加下划线，悬停时才出现下划线。
- 链接不用主色。蓝色用于焦点和明确的状态提示（原则 8）。

状态色的含义固定，全系统不变：

| 色 | 含义 | 例子 |
|---|---|---|
| 成功 `success` | 已完成、已生效、通过 | 已生效、已审批 |
| 警示 `warning` | 可以继续，但要注意 | 已退回、即将到期、折扣超限 |
| 错误 `danger` | 必须处理才能继续，或已经失败 | 必填未填写、已逾期、上传失败 |
| 信息 `info` | 中性的说明，正在进行 | 审批中、处理中、开发中 |
| 等待 `wait` | 这一步在等别人，或者还没开始。圆点是信息色空心圆 | 待确认、待对方回复、未开始 |
| 无色（`muted`） | 没有好坏 | 草稿（空心圆）、已作废、已关闭 |

- 一种颜色只表达一种含义。优先级、类别、负责人不用状态色。
- 「等待」和「草稿」都是空心圆：等待用信息色，草稿用次要文字色。两者旁边都有文字，不靠圆点区分。

分类色的规则：

- 同一个类别在全系统用同一个序号。例如「软件」是 `cat-1`，在报价明细、产品列表、图表里都是 `cat-1`。
- 一页里出现的分类色不超过 6 种。超过 6 类时，多出的类别用无色标签（`.wb-tag.is-plain`）。
- 标签写法：`<span class="wb-tag" data-cat="2">服务</span>`。标签是描边胶囊：1px `--wb-line` 描边，左侧 6px 分类色圆点，文字用 `--wb-ink-2`，不铺底色。
- 图标写法：`<svg class="wb-cat-icon" data-cat="2">`。
- 头像底色是分类色的 18%，序号由 `avatarCat()` 从姓名算出。同一个人在全系统同一个颜色，写法见 [3-控件.md](3-控件.md) 3.11。
- 文件图标按类型取分类色，序号由 `fileCat()` 从扩展名算出：PDF 用 `cat-5`，Office 文档和表格用 `cat-1`，图片用 `cat-3`，图纸（DWG、STEP 等）用 `cat-2`，其他类型不着色。

## 2.4 字体

| 用途 | 字体 | 变量 |
|---|---|---|
| 界面文字 | Inter Variable，中文回退苹方、微软雅黑、思源黑体 | `--wb-font` |
| 数字、金额、编号、日期 | 同界面文字，开启等宽数字（`font-variant-numeric: tabular-nums`），写法 `.wb-tnum` | `--wb-font` |
| 代码、密钥这类要逐个字符核对的文字 | JetBrains Mono，回退系统等宽字体 | `--wb-mono` |

- 管理界面只用无衬线字体，不用衬线体。
- Inter 随仓库自托管在 `assets/fonts/`，已内嵌进 aham.css 的 `@font-face`，不从第三方服务器下载。JetBrains Mono 没有随仓库提供，产品自行安装或托管，缺失时用系统等宽字体。
- 金额、数量、单价和就地变化的计数用等宽数字（`.wb-tnum`），数字列右对齐，小数位数在同一列里一致。这几类数字要上下按位比较大小，或者在原处变化时宽度不能变。
- 编号和日期不用等宽数字。Inter 的比例数字更紧凑，编号和日期也不需要按位比较（Linear 的编号同样用比例数字，见 docs/research/Linear字体字号-调研.md 4.4）。
- 等宽数字用 Inter 的 `tabular-nums`，不换等宽字体：字形和旁边的文字一致，宽度更窄。
- 20px 及以上的标题由 Inter 的光学尺寸轴自动换成显示字形（`font-optical-sizing: auto`，浏览器默认开启），效果相当于 Linear 标题用的 Inter Display，不另加字体文件。

## 2.5 字号和字重

字号的档数学 Linear（[docs/research/Linear字体字号-调研.md](../docs/research/Linear字体字号-调研.md)）：工作台只用正文和辅助两档。字号按中文定：中文笔画多，13px 时笔画挤在一起；对照 Claude 客户端的中文界面（正文 14–15px），正文取 14px，辅助信息 12px。层级靠档数少来保证，不靠把正文调小（原则 7）。

| 变量 | 字号 | 用途 |
|---|---|---|
| `--wb-text-xs` | 12px | 辅助信息：分组名、计数、表单提示、写在值上方的字段标签、日期和时间等元数据。全系统最小字号，不用 11px 及以下 |
| `--wb-body` | 14px | 正文、列表、表格、按钮、标签、侧栏、页眉标题和面包屑、分区标题、和值同一行的字段标签 |
| `--wb-text-base` | 14px | 弹窗标题；对外填报页的正文 |
| `--wb-title` | 20px | 记录详情页、单据页和设置页的标题，打印件标题。一页只出现一次 |
| `--wb-total` | 24px | 金额汇总的大数字；记录详情页关键信息的数 |
| `--wb-touch-input` | 16px | 触屏上的输入框，防止 iOS 放大页面 |

1. 工作台页面（列表、详情、单据、设置）一屏只出现 14px 和 12px 两档字号，标题、金额汇总和关键信息的数除外。
2. 页眉里的页面名称和面包屑用 14px，字重 500，不再放 20px 的页面大标题。列表页没有大标题。
3. 层级先靠颜色深浅，再靠字重，最后才靠字号。正文和要读的值用 `--wb-ink`，标签、时间和说明用 `--wb-muted`；`--wb-ink-2` 只给控件里的次要文字（视图页签的其他项、标签文字），不用于记录内容。
4. 字重三档：400 正文；500 当前项、强调、分区标题、页眉标题；600 给 20px 的标题、记录详情页的区块标题（要点、阶段条、工作记录）和关键信息的数。不用 700。
5. 对外填报页和打印件不受第 1 条约束：对外填报页标题 20px，手机上输入框 16px。
6. 行高写成像素，让文字和图标落在整像素上：14px 文字用 22px（`--wb-leading`），12px 文字用 16px（`--wb-leading-xs`）。标题 1.3，记录详情页正文的长段落 1.75。
7. 字段标签两种写法，颜色都是 `--wb-muted`：写在值或输入框上方的用 12px（单据和弹窗的字段名、单据头要点、预览面板、关键信息）；和值写在同一行的用 14px，和值同一基线（属性栏）。对外填报页除外：标签是要外部人员回答的问题，用正文字号和 `--wb-ink-2`。

详情页、单据页和设置页的标题都用 `--wb-title`（20px）。

## 2.6 间距

间距按 4px 递进：`--wb-s1` 4、`s2` 8、`s3` 12、`s4` 16、`s5` 24、`s6` 32、`s7` 48、`s8` 64。

| 位置 | 取值 |
|---|---|
| 单据页左右边距 | `--wb-page-gutter` 32px，1600px 以上 48px |
| 单据分区之间 | 32px（`s6`） |
| 分区标题到内容 | 16px |
| 表单字段之间 | 上下 16px，左右 24px |
| 标签到值 | 4px |
| 按钮之间 | 8px |

| 变量 | 取值 | 用途 |
|---|---|---|
| `--wb-list-row` | 44px | 单行列表的行高（[4-页面.md](4-页面.md) 4.3 的 `.wb-list-rows`） |
| `--wb-row` | 36px | 明细表和数据表格的行、表头、分组行的默认高度 |
| `--wb-row-compact` | 32px | 紧凑档，用户在显示选项里切换 |
| `--wb-row-double` | 48px | 两行内容的行（名称加编码） |
| `--wb-control` | 32px | 按钮、输入框、下拉 |
| `--wb-header-control` | 28px | 小号按钮和输入框：工具栏、页眉、弹层 |
| `--wb-field` | 28px | 表格单元格里的输入框 |
| `--wb-hit` | 32px | 小控件的最小点击区域 |
| `--wb-touch` | 44px | 触屏的行高和点击区域 |
| `--wb-header-row` | 44px | 页眉横条 |
| `--wb-nav-item` | 28px | 侧栏的导航项，项与项之间 2px |
| `--wb-icon` | 16px | 图标 |

同一张表格只用一档密度：表头、分组标题和数据行同高，随密度一起变。单行列表的分组行 36px，数据行 44px。640px 以下或粗指针（触屏）时，所有行高换成 44px。

单行列表用 44px 而不用 36px：Linear 截图实测列表行约 48px，14px 文字配宽松的行距，信息密度靠一行一个对象、不折行来保证（原则 7）。1440×900 的窗口里，44px 的列表一屏约 17 行。

## 2.8 圆角、线条、阴影

| 项 | 规则 |
|---|---|
| 圆角 | 小元素 4px（`--wb-radius-sm`：勾选框、键位提示）；控件和弹层 8px（`--wb-radius`：按钮、输入框、提示条、菜单、弹层）；弹窗、命令面板、上传区 12px（`--wb-radius-lg`）；胶囊（`--wb-radius-pill`）只用于开关、进度条、头像和标签。侧栏、内容区、侧面板和明细表这些区域不加圆角，按 Claude 客户端和 Linear 的做法，靠底色和细线分开 |
| 线条 | 分隔线宽 `--wb-hairline`，固定 1px。0.5px 的线在 2 倍屏上颜色发虚，不用。颜色分三档：工作面和外框的交界 `--wb-edge`，分栏 `--wb-line`，行与行之间 `--wb-line-soft`，见 [11-交互.md](11-交互.md) 11.1。输入框、勾选框和开关的描边固定 1px `--wb-line-strong`。按钮不画描边，次要按钮用 `--wb-button` 底色。表格只画横线，不画竖线。分区之间不画线，用间距 |
| 阴影 | 静止的元素没有阴影。弹层、菜单、轻提示用 `--wb-shadow-pop`，弹窗用 `--wb-shadow-float`，两者都带一圈 1px `--wb-pop-edge` 外缘线，弹层不再另画边框 |

## 2.9 图标

- 图标集用 Lucide（ISC 许可），雪碧图在 `assets/icons/aham-icons.svg`，写法 `<svg aria-hidden="true"><use href="assets/icons/aham-icons.svg#i-search"/></svg>`。
- 默认 16px，描边在 24 网格里是 2，画成 16px 约 1.33px，和 14px 正文的笔画一样粗；颜色跟随文字（`currentColor`）。只有图标的按钮仍保持 28px 或 32px 的点击区域。例外两处：动态里 20px 圆底里的事件图标用 12px，工作记录 24px 圆底里的类型图标用 14px。
- 图标只放在能加快识别的位置：侧栏导航、状态和阶段、文件类型、只有图标的按钮。列表行里最多一个阶段图标或状态图标，正文标题前不放图标。
- 图标颜色只有四种来源：文字色、主色（焦点、当前项、工作记录里跟进的类型圆标）、状态色（状态图标）、分类色（类别图标）。
- 只有图标的按钮必须有 `aria-label`，悬停时显示名称（`data-tooltip`）。
- 不用 emoji、插画和彩色图形。

## 2.11 暗色

- 根节点 `data-theme="dark"` 切暗色，`data-theme="light"` 固定亮色，不写时跟随系统。
- 暗色的每个颜色单独取值，不是亮色反转；`color.dark` 和 `color.light` 的键必须一一对应，构建脚本会检查。
- 打印时一律用亮色，不论屏幕是哪个主题。
- 文件预览里的原稿不随主题反色。

## 2.12 主题生成

产品换品牌色或做新主题时，用三个值生成整套中性色和主色，不逐个手调。做法参考 Linear 2024 年改版的公开说明：Linear 把每套主题的 98 个变量减成底色、主色和对比度三个，计算在 LCH 色彩空间里做，不同色相在同一亮度下看起来一样亮（[How we redesigned the Linear UI](https://linear.app/now/how-we-redesigned-the-linear-ui)）。Linear 没有公开具体算法，Aham 的算法是自己写的：每个键保留手调值相对底色或主色的亮度差，对比度按比例放大文字和线的亮度差。

| 输入 | 含义 | Aham 默认值 |
|---|---|---|
| 底色 `base` | 侧栏和外框的底色，决定中性色的色相、彩度和明暗 | 亮色 `#EDECEB`，暗色 `#0B0B0B` |
| 主色 `accent` | 主按钮、焦点框的颜色 | `#336EE8` |
| 对比度 `contrast` | 30–100，越大文字和线越深；60 得到 tokens.json 的手调值 | 亮色 60，暗色 60 |

- 生成函数是 `scripts/theme.mjs` 的 `generateTheme({ base, accent, contrast })`，输出 `color.light` 或 `color.dark` 的全部中性色和主色键。状态色和分类色不由它生成，保持手调的取值。
- 生成结果必须通过 2.3 的全部对比度要求。`node scripts/theme.mjs --check` 检查默认主题和 3 个样例主题。达不到时提高 `contrast`，不手改单个颜色。
- tokens.json 里的亮色和暗色是手调后核对过的取值，作为生成的参照。用默认输入生成时，`--check` 列出和手调值相差超过 ΔE 3 的键；9.0 发布时没有这样的键。
- 生成函数在 9.0 只作为工具提供，示例页仍用 tokens.json 的手调值。
