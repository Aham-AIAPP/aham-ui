# Aham UI 7.2 工作台规划

本文接续 [workbench-plan.md](workbench-plan.md)（7.1）。7.1 做了单据页，7.2 补列表页、侧面板和交互层。参考项目是 [ln-dev7/circle](https://github.com/ln-dev7/circle)（MIT，读取版本 b0ba7dd）。本次仍不导入 Circle 的代码和依赖。

## 1. 分工

- Aham 管视觉：颜色、字体、圆角、阴影、状态写法（6px 点 + 文字）、动效时长、图标库。
- Circle 管结构：页面框架、疏密安排、筛选与视图、侧面板、键盘与命令面板。
- 两边冲突时按 Aham 铁规走。例如 Circle 的状态格只放彩色图标，工作台里改为点 + 文字。
- 实现保持零 npm 运行依赖。CRM 前端是 Jinja2 SSR + 原生 JS，交互全部用原生 JS 实现，不引入 cmdk、Radix。工作台的行为写在 `workbench.js`（与 `workbench.css` 对应），不放进旧的 `aham-ui.js`。

## 2. 已定决策（2026-09-30）

| # | 事项 | 决定 | 理由 |
|---|---|---|---|
| 1 | 侧栏展开宽度 | 240px；收起为 52px 图标栏 | 148px 文字区约 7 个 13px 汉字，二级菜单缩进后约 5 个，放不下常见 ERP 菜单名。数字是按 Circle 内边距估算的 |
| 2 | 视图切换的选中色 | 灰底深色字 | 选中一律用灰是 Aham 现行规则。单据内容页签的蓝色下划线继续保留，AGENTS.md 已列为允许用蓝的位置 |
| 3 | 列表默认行高 | 36px，显示选项里可切 32px | 36px 是全局 standard 档，32px 是 compact 档。Circle 为 44px |
| 4 | React 适配 | 暂不做，先做原生版 | 7.1 规划已把 React 适配排在后面 |

待定：orchisky-demo-design 的 Platform 画像目前按 Ant Design 5 做，属于受控例外。是否改用工作台由用户决定。

## 3. Circle 紧凑感的来源

以下取自 Circle 源码：

- 列表页顶部是两条 40px 横条，共 80px，没有大标题区（`main-layout.tsx:31-34`，各 header 的 `h-10`）。
- 工具栏控件高 28px（`button.tsx:24`）。
- 字号以 12px、14px 为主：`text-xs` 出现 334 次，`text-sm` 出现 328 次。
- 列表行高 44px（`issue-line.tsx:29`），比 Aham 的 36px 高。

工作台要紧凑，关键是用 40px 横条页眉替换 DESIGN.md §8.4 的大标题页眉。下面 3 个 Aham 现有值和 Circle 相同，可以直接复用：

- `density.compact.controlHeight` 28px
- `workbench.breadcrumbHeight` 40px
- `overlayWidth.drawer` 400px

## 4. 逐项处理

| Circle 做法 | 工作台处理 |
|---|---|
| 侧栏加内嵌内容卡，≥1024px 时外距 8px、1px 边框 | 结构照用，靠底色分层：侧栏 `tier2-panel`，内容 `tier1-white`，不加边框 |
| 侧栏收起时整个藏掉，⌘B 切换，状态不持久 | 收起为 52px 图标栏；⌘B / Ctrl+B 切换；记住收起状态 |
| 1–2 条 40px 页眉横条 | 照用。第一条放位置、视图切换、搜索；第二条放条数、筛选、面板开关、显示选项 |
| 列表单行、固定列宽，窄屏隐藏次要列 | 照用；行高 36 / 32px；状态列用点 + 文字 |
| 分组组头吸顶、显示条数，不能收起 | 照用并补收起 |
| 四段式筛选标签，条件写进 URL，「被筛掉条数」放底部 | 标签和 URL 照用；条数按 §8.5 放顶部 |
| 显示选项：列表 / 看板、分组、排序、列开关，改过默认值亮橙点 | 照用，加疏密和列顺序；改过默认值用文字提示 |
| 右侧面板挤开内容，一次开一个，7 种宽度 | 机制照用；宽度只留 240px 和 400px 两档 |
| 预览面板只在时间线上用 | 列表行按空格预览、回车进详情（§8.9 已有此规则） |
| 行内编辑：弹出可搜索列表 | 照用；加字段权限、审批后锁定、保存失败回退 |
| 右键菜单 6 组，删除在最后；行内 / 右键 / ⌘K 同一批操作 | 照用，三处读同一份操作定义 |
| ⌘K 命令面板，按页面给操作 | 照用；放菜单直达、按单号查记录、当前记录操作三类 |
| 新建窗口 750px，带「继续创建」 | 宽度不超过 640px；保留「继续新建」；复杂单据用整页表单 |
| 设置页四层：外框 / 分区 / 卡片 / 设置行 | 分层照用，卡片边框改横线 |
| 看板拖卡片改状态 | 走审批的单据不用 |
| 周期、分诊、Initiative、代码评审、Agent 页 | 不迁移 |

Circle 里有几处半成品，不照抄：31 个快捷键提示中只有 ⌘K、⌘B、Esc、⌘Enter 等少数接了处理函数；负责人行内修改不保存；主导航无选中态。

## 5. 需自建的部分

以下 6 项 Circle 没有，工作台列表页需要：

1. 勾选多行与批量操作条
2. 服务端分页或虚拟滚动
3. 上下方向键在行间移动
4. 拖动列宽、固定左侧列（接 §8.13 冻结首列规则）
5. 分组收起
6. 主导航选中态

另需「查询方案」（保存一组筛选条件）。Circle 的视图保存机制尚未核对。
