# Aham UI 8.0 重构方案

日期 2026-10-17。依据：[aham-ui-优化规划草案.md](aham-ui-优化规划草案.md) 和你在第 2、3 轮的回复。

## 1 已定的方向

| 项 | 结论 |
|---|---|
| 范围 | 只保留网页管理界面一条轨道。删除 macOS 应用、Office 文档、HTML 邮件三条轨道，删除内容页样式和「媒体与对话」组件 |
| 单据页 | 只留一版，以 7.6 PC 版式为基础，交互规则按 SAP Fiori 重写 |
| 底色 | 低饱和暖灰，内容区纯白，不用米黄 |
| 颜色 | 主色钢蓝 `#336EE8` 保留；增加状态色 4 个、分类色 6 个，各有用途范围 |
| 行高 | 默认 36px，紧凑档 32px，删除 PC 上的 44px |
| 规则 | 旧铁规与新方向冲突的，按新方向重写，不保留「例外」写法 |
| 版本 | 8.0.0，不兼容 7.x |

## 2 新目录结构

```
aham-ui/
├── README.md            简介、目录、使用方法
├── AGENTS.md            AI 读取顺序和交付前自查，唯一入口
├── CHANGELOG.md
├── LICENSE
├── index.html           在线首页：色板、文字样式、示例入口
├── tokens.json          全部取值，唯一来源
├── aham.css             生成文件：令牌变量 + src/ 全部样式，页面只引这一个
├── aham.js              行为脚本，ES 模块，无依赖
├── rules/               规范正文
│   ├── 1-总则.md        适用范围、原则、术语
│   ├── 2-视觉.md        颜色、字体、间距、圆角、线条、图标、动效、暗色
│   ├── 3-控件.md        控件清单和选型表
│   ├── 4-页面.md        外框、页型选择、列表、详情、设置
│   ├── 5-单据.md        新建、录入、修改、草稿、校验、提交、审批、状态、删除、打印
│   ├── 6-反馈.md        消息分级、提示条、弹窗、空状态、加载
│   ├── 7-键盘与命令.md  快捷键、命令面板、右键菜单
│   ├── 8-AI协作.md
│   └── 9-验收.md        无障碍和交付检查
├── components/          控件和组合的机读契约（JSON）
├── src/                 样式源文件，按主题分文件
├── assets/              fonts/、icons/、截图
├── examples/            示例页
├── scripts/             build.mjs（生成 aham.css）、lint.mjs
├── tests/
└── research/            调研和规划记录（原 docs/）
```

## 3 文件去向

| 现有文件 | 去向 |
|---|---|
| design-system/ 整个目录 | 拆开，放到上面的根目录结构里 |
| DESIGN.md、WORKBENCH.md、DESKTOP.md | 内容重写进 rules/，原文件删除 |
| SKILL.md、AGENTS.md、library-consumption.json | 合并为根目录 AGENTS.md |
| design-system/README.md | 并入根目录 README.md |
| aham-ui.css、colors_and_type.css、components.css、aham-ui.js | 删除（内容页样式） |
| workbench.css、workbench-tokens.css、desktop.css 及两个 .in 模板 | 拆成 src/ 下的分文件，由 build.mjs 生成 aham.css |
| workbench.js | 改名 aham.js |
| aham-ui-office.md | 删除（Office 轨道） |
| preview/ 下 17 个基础组件预览、ui_kits/dashboard | 删除，改为 examples/ 里一个控件总览页 |
| preview/ 下 5 个工作台预览 | 移入 examples/ |
| examples/ 下基于内容页样式的 14 个演示页 | 删除 |
| examples/object-page、desktop-workbench、crm-quotation | 合成单据示例，按新规则重做 |
| docs/ | 移到 research/ |

类名前缀 `wb-` 和根类 `.aham-workbench` 保持不变，理由是 aham.js 里有大量引用，改名的收益小、出错面大。CSS 变量统一为 `--wb-` 一套。

## 4 实施顺序

1. 搬目录、删文件，构建脚本改为生成单一 aham.css。
2. 改 tokens.json 取值：暖灰、状态色、分类色、行高。
3. 重写 rules/ 九个文件。
4. 重做示例：列表、单据（含新建、编辑、提交、打印预览）、详情、设置、控件总览。
5. 重写测试和 lint，更新 README、AGENTS.md、首页。
6. 截图核对亮色、暗色和三档宽度，开 draft PR。

旧版本在 git 历史和 7.6.0 发布里都能找回。
