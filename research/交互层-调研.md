## Claude 客户端量取

- 遮罩：侧栏 `#EDECEB` 在遮罩下变成 `#8E8E8D`，折算黑色约 40%。【实测】
- 设置弹窗全白；分类栏和内容之间 `#E5E5E5`，标题下 `#E0E0E0`，设置行之间 `#F3F3F3`。【实测】
- 设置弹窗当前分类底色 `#E5E5E5`，次要按钮底色 `#F2F2F2`。【实测】
- 账户菜单：1pt 描边加阴影，圆角约 12pt；菜单打开时触发按钮保持深色底。【实测】
- 偏好放在账户菜单打开的弹窗里，改了立即生效，没有保存按钮。【实测，截图里没有保存按钮】
- 菜单和弹窗的时长和曲线：截图量不到。第 11 章的时长取自公开规则，没有和 Claude 客户端逐帧对照。【推测】

## 采用的做法

| 主题 | 做法 | 依据 |
|---|---|---|
| 层级 | 5 层；只有浮层和模态有阴影；同层分区用线 | Claude 实测、Linear |
| 分隔线 | 三档：外框交界、分栏、行间 | Claude 实测 |
| 状态 | 悬停深一档，按下和选中深两档；打开中保持按下色 | Claude 实测、Linear |
| 按下 | 独立按钮缩到 0.97，行和导航项只变色 | Emil Kowalski |
| 悬停 | 只对指针设备；移入立即，移出淡出 | Vercel |
| 动效 | 按频次决定；只动 transform 和 opacity；出现慢于消失 | Emil Kowalski |
| 减少动态效果 | 去掉缩放和位移，保留淡入淡出 | Vercel、Apple |
| 容器 | 按 6 条从上往下判断；偏好用分栏弹窗，工作区设置用新页面 | Claude 实测、Apple、NN/g |

## 浏览器实测

2026-10-25 在 Chromium 里用 Playwright 测 examples/ 下全部样板页。【实测】

- 描边按钮：静止 `#FFFFFF`，悬停 `#F3F3F2`，按下 `#EBEBEA`，按下时 `transform` 为 `scale(0.97)`。
- 菜单：打开后 100ms 内 `opacity` 由 0 到 1，缩放由 0.97 到 1；触发按钮 `aria-expanded=true`。
- 菜单关闭：播放消失后隐藏，焦点回到触发按钮。
- 命令面板：打开后第一帧 `opacity` 为 1。
- 触屏（模拟 iPhone 13）：点过的按钮不留悬停色；分栏弹窗铺满 390×664。
- 减少动态效果：按下和菜单出现时 `transform` 为 `none`，淡入保留。
- 8 个样板页控制台没有报错。
