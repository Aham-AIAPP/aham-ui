# 11 交互

本章落实设计理念的原则 6、11、12。界面上每个元素怎样分层、怎样回应鼠标和键盘、怎样出现和消失，都按本章做，其他章只引用。示例：[examples/interaction.html](../examples/interaction.html)。样式集中在 `src/interaction.css`，出场动效由 `aham.js` 的 `leave()` 播放。

规则的来源：表面层级和分隔线按 Claude 桌面客户端截图量取；Linear 2024 年和 2026 年改版的公开说明；状态和动效参考 Vercel Web Interface Guidelines 和 Emil Kowalski 公开的动效规则；容器选用参考 Apple Human Interface Guidelines 和 NN/g。调研记录见 [research/交互层-调研.md](../research/交互层-调研.md)。

## 11.1 表面层级

界面分 5 层。层越高，离用户越近。

| 层 | 用在 | 底色 | 边 | 阴影 |
|---|---|---|---|---|
| 0 外框 | 侧栏、窗口边缘 | `--wb-canvas` | 无 | 无 |
| 1 工作面 | 内容区、侧面板、页眉 | `--wb-bg` | 和外框交界画 `--wb-edge`，直角 | 无 |
| 2 嵌入的输入区 | 评论框、AI 输入框 | `--wb-bg` | 1px `--wb-line-strong`，圆角 `--wb-radius-lg` | 无 |
| 3 浮层 | 菜单、下拉、筛选、悬停提示 | `--wb-pop-bg` | 1px `--wb-line` | `--wb-shadow-pop` |
| 4 模态 | 弹窗、新建弹窗、分栏弹窗、命令面板 | `--wb-pop-bg` | 无 | `--wb-shadow-float`，遮罩 `--wb-scrim` |

- 第 0、1 层是区域，直角，铺到窗口边缘，不留外边距。圆角只用在第 2–4 层和区域里的控件上。Claude 客户端和 Linear 截图里都是这样：内容区紧贴侧栏，中间一条细线。
- 同一层里的分区用线，不换底色。侧面板和内容区都是白底，中间一条 `--wb-line`。分栏弹窗的分类栏和内容也是白底。
- 分隔线分三档：工作面和外框的交界用 `--wb-edge`，分栏用 `--wb-line`，行与行之间用 `--wb-line-soft`。
- 只有第 3、4 层有阴影。第 2 层的输入区靠描边和圆角浮起，不加阴影。
- 遮罩是黑色 40%，按 Claude 客户端的设置弹窗量取。暗色是黑色 50%。
- 暗色主题里层越高底色越亮：外框 `#0B0B0B`，工作面 `#151515`，浮层 `#1A1A19`。

## 11.2 状态

可以点的元素有 5 个状态：静止、悬停、按下、选中或当前、打开中。底色按「静止 → 悬停深一档 → 按下深两档」递进，选中和当前停在深两档。

| 元素 | 悬停 | 按下 | 选中或当前 | 打开中 |
|---|---|---|---|---|
| 侧栏导航项 | `--wb-nav-hover` | `--wb-nav-selected` | `--wb-nav-selected`，字重 500 | `--wb-nav-selected`（账户按钮） |
| 白底上的行：列表行、菜单项、设置导航 | `--wb-hover` | `--wb-selected` | `--wb-selected` | — |
| 描边按钮、文字按钮、图标按钮 | `--wb-hover` | `--wb-selected`，缩到 `--wb-press-scale` | — | `--wb-selected` |
| 主按钮 | `--wb-action-hover` | `--wb-action-press`，缩到 `--wb-press-scale` | — | — |
| 分段按钮、视图页签 | `--wb-hover` | `--wb-selected` | 白底加描边 | — |
| 输入框 | 描边深一档 | — | 焦点框 | 下拉打开时保持焦点框 |

- 打开中指触发按钮的浮层正开着。`openPopover()` 给触发按钮设 `aria-expanded="true"`，按钮保持按下的颜色，直到浮层关闭。
- 缩放只用在独立的按钮上。行、导航项和菜单项面积大，缩放会让文字抖动，只变色。
- 悬停样式只对鼠标和触控板生效。`scripts/build.mjs` 把 `src/` 里带 `:hover` 的单行规则包进 `@media (hover: hover) and (pointer: fine)`，触屏上点过的按钮不会留下悬停色。和焦点共用的规则不包。
- 禁用的控件没有悬停和按下。
- 焦点框沿用 2.2：2px `--wb-blue`，只在键盘操作时出现（`:focus-visible`）。

## 11.3 悬停的过渡

- 移入时立即变色，移出时用 `--wb-fast` 淡出。鼠标扫过一排按钮时，留下一条渐淡的痕迹，不会闪。
- 悬停提示：第一个延迟 500ms 出现，之后 300ms 内相邻元素的提示不再延迟，也不再淡入。触屏上没有悬停提示。

## 11.4 动效

动不动按使用频次决定：每天上百次的操作不加动效，每天几十次的只加 150ms 以内的淡入，偶尔发生的加 200ms 的过渡。

| 频次 | 元素 | 动作 | 时长 |
|---|---|---|---|
| 每天上百次 | 命令面板、快捷键、列表上下移动、视图页签 | 不加动效 | 0 |
| 每天上百次 | 悬停 | 移入立即变色，移出淡出 | `--wb-fast` |
| 每天上百次 | 按下 | 底色加深，按钮缩到 0.97 | `--wb-instant` |
| 每天几十次 | 菜单、下拉、筛选 | 从触发按钮一侧淡入，由 0.97 放大到 1；消失时淡出并缩回 | 出现 `--wb-pop`，消失 `--wb-instant` |
| 每天几十次 | 悬停提示 | 淡入 | `--wb-fast` |
| 每天几十次 | 分组折叠 | 箭头旋转，行直接出现 | `--wb-fast` |
| 偶尔 | 弹窗、新建弹窗、分栏弹窗 | 遮罩淡入，弹窗淡入并由 0.97 放大到 1 | 出现 `--wb-base`，消失 `--wb-pop` |
| 偶尔 | 预览面板 | 淡入并从右侧移入 8px | `--wb-base` |
| 偶尔 | 轻提示 | 淡入并上移 8px | 出现 `--wb-base`，消失 `--wb-pop` |
| 偶尔 | 设置页保存栏 | 淡入并上移 8px | `--wb-base` |

不加动效的地方：

- 用户正在读或正在操作的数据：列表行、数字、排序和筛选的结果。
- 翻页和页面切换。
- 由键盘触发的操作。
- 宽、高、外边距、位置这些会引起重新排版的属性。只动 `transform` 和 `opacity`。

写法：

- 出现用 CSS `@starting-style`。不支持的浏览器直接显示，不影响使用。
- 消失用 `leave(el, done)`：它给元素加 `data-leaving`，等过渡结束再隐藏或移除。切换到另一个浮层时，旧浮层直接隐藏，不播放消失。
- 浮层和触发按钮对齐：按钮在窗口左半边时左对齐，在右半边时右对齐，`openPopover()` 默认按这条放置。变形原点在触发按钮一侧。弹窗居中，原点在中心。
- 消失时浮层和弹窗淡出并缩回 0.97，和出现的方向相反；轻提示只淡出。
- 缓动：出现、消失、变色用 `--wb-ease`，在屏幕内移动用 `--wb-ease-move`。不用加速曲线、回弹和弹跳。
- 用 `transition`，不用 `@keyframes`，过渡能被下一次操作打断。骨架屏的闪烁是唯一的 `@keyframes`。
- `scripts/lint.mjs` 检查 `src/`：不写 `transition: all`，不对宽高和位置做过渡，时长必须用变量。

## 11.5 减少动态效果

系统开启「减少动态效果」时，去掉缩放、位移和旋转，保留淡入淡出和变色。骨架屏不闪烁。减少的意思是更少、更轻，不是全部去掉：淡入淡出仍然告诉用户东西从哪里来。

## 11.6 容器选用

从上往下判断，第一条对上的就是答案。

1. 只改当前元素的一个值，或选一项：页内编辑或浮层。
2. 要看一条记录，又不离开列表：侧面板。
3. 操作不可撤销，或缺了信息就不能继续：确认弹窗（[6-反馈.md](6-反馈.md) 6.3）。
4. 任务需要链接、超过一屏、分多步或需要对照别的信息：新页面。
5. 一屏内能填完的新建：新建弹窗。
6. 只影响自己的偏好：账户菜单里的「偏好设置…」，打开分栏弹窗。

| 容器 | 用在 | 尺寸 | 关闭方式 | 约束 |
|---|---|---|---|---|
| 页内 | 改字段、行内展开、字段错误、批量操作条 | — | — | 错误写在出错的位置 |
| 浮层 | 选值、筛选、更多操作、账户菜单、日期 | 160–320px 宽 | 点外面、选完、Esc | 一次一个。不从浮层再开浮层，子菜单在原位替换。不放警告 |
| 侧面板 | 预览、属性、汇总 | 属性 288px，预览 400px | 再点一次按钮；浮在内容上时 Esc | 非模态，焦点留在原处。一次一个 |
| 确认弹窗 | 不可撤销的操作、必须补的信息 | 400px | 取消、动作按钮、Esc | 规则见 6.3 |
| 新建弹窗 | 一屏内能填完的新建 | 640px | 取消、创建、Esc | 有内容时原地问，不叠第二个弹窗 |
| 分栏弹窗 | 个人偏好 | 880px，最高 640px，左栏 200px | 关闭按钮、Esc、点遮罩 | 改了立即生效，没有保存按钮。要确认的操作在行内原地问 |
| 新页面 | 单据、记录详情、工作区设置 | 整个内容区 | 返回、面包屑 | 有链接，可分享。工作区设置有保存栏 |
| 命令面板 | 跳转和执行命令 | 640px | Esc、执行后 | 没有动效 |

- 账户菜单从侧栏底部的账户按钮打开，第一行是当前账号，下面是偏好设置、键盘快捷键、工作区设置，最后一组是退出登录。命令面板里也有「偏好设置…」。不给偏好设置配 ⌘/Ctrl + ,：Safari 和 Chrome 在 macOS 上把这个组合键留给浏览器自己的设置，网页收不到。
- 鼠标打开弹窗时，焦点放在内容区（`tabindex="-1"`），不显示焦点框；键盘打开时焦点放在当前分类上。
- 一次只开一个模态弹窗。弹窗里需要再确认时，在弹窗里原地问。
- Esc 每次只关最上面一层，关闭后焦点回到打开它的位置（[4-页面.md](4-页面.md) 4.1）。
- 640px 及以下，分栏弹窗铺满屏幕，分类栏变成顶部一行。

## 11.7 验收

- 按住每种按钮 150ms，截图里底色比悬停深一档，独立按钮的 `transform` 是 `scale(0.97)`。
- 菜单打开时，触发按钮的 `aria-expanded` 是 `true`，底色是 `--wb-selected`。
- 菜单打开后每 25ms 取一次 `opacity`：第一帧 0，150ms 内到 1。命令面板打开后第一帧就是 1。
- 用触屏设备点一下按钮，抬起后底色回到静止。
- 开启「减少动态效果」后，按下和浮层出现时 `transform` 都是 `none`，`opacity` 仍有过渡。
- 弹窗遮罩下的侧栏颜色：亮色 `#EDECEB` 变成 `#8E8D8D`。
